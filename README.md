# Orbit Breaker

Arcade espacial feito com Phaser 3 e Vite. Pilote a nave, destrua meteoros e tente sobreviver a ondas cada vez maiores.

## Executar

```sh
npm install
npm run dev
```

## Controles

- `W` ou `↑`: acelerar
- `A` / `D` ou `←` / `→`: girar
- `Espaço`: disparar
- `P`: pausar ou retomar
- Celular: use os controles na tela

O recorde fica salvo localmente neste navegador. Para verificar a versão de produção, rode `npm run build`.
