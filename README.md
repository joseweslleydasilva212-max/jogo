# Orbit Breaker

Arcade espacial feito com Phaser 3 e Vite. Pilote a nave, destrua meteoros e tente sobreviver a ondas cada vez maiores.

## Recursos

- Três modos selecionáveis: Defesa do Satélite, Caça aos Chefes (um por onda) e Clássico (ondas apenas de asteroides).
- Ondas de sobrevivência de 30 segundos e chefes a cada cinco ondas, com disparos direcionados.
- Meteoros ficam mais rápidos conforme a missão avança.
- Cores Solar e Plasma desbloqueadas ao alcançar as ondas 5 e 10.
- Recorde de pontuação, melhor onda e cor escolhida salvos neste navegador; o fim da partida mostra a duração.
- Efeitos sonoros, música e vibração configuráveis pelos botões no cabeçalho.

## Executar

```sh
npm install
npm run dev
```

## Controles

- `W` ou `↑`: acelerar
- `A` / `D` ou `←` / `→`: girar
- `Espaço`: disparar
- `E`: usar habilidade da nave
- `P`: pausar ou retomar
- Celular: use os controles na tela

Para verificar a versão de produção, rode `npm run build`.
